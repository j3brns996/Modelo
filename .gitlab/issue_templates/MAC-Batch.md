## Field guide

**Request type:** Choose what should happen. Nothing is submitted until you review the native issue form.

**Batch change type:** Every subject in this batch will use this operation.

Choose: `add`, `change`, `revoke`.

**Subject type:** A model describes capabilities. An offering records approved access. Evidence supports facts; conditions describe rules for use. Revoke batches support offerings only.

Choose: `model`, `offering`, `evidence`, `vendor`, `inference-service`, `condition`.

**Subject identities:** One stable lowercase ID per line, up to 25. Every record uses the same type and operation. Use the lookup to add existing records.

[Look up records](https://j3brns996.github.io/Modelo/propose/?operation=batch#lookup-subject_identities)

**Purpose:** In one sentence, what do you need? For example: provide a reviewed model for document summarisation.

**Requested outcome:** Describe what should be true when the request is complete. Use the lookup to reference models, services or exact condition versions.

[Look up records](https://j3brns996.github.io/Modelo/propose/?operation=batch#lookup-requested_outcome)

**Why is this needed?:** Explain who needs this and why the current catalogue is insufficient.

**Evidence source type:** How was the bounded observation obtained?

Choose: `first-party-read-api`, `official-documentation`.

**Evidence source URL:** Official HTTPS source for the batch observation.

**Opaque scope reference:** A non-secret internal scope label. Never enter an account ID.

**Provider partition:** Provider partition for the observation scope.

Choose: `aws`, `aws-cn`, `aws-us-gov`.

**Source region:** Region in which the read observation was made.

**Inference service:** Choose the governed service for this batch, such as AWS Bedrock.

[Look up records](https://j3brns996.github.io/Modelo/propose/?operation=batch#lookup-inference_service)

**Supporting observations:** Optional. One observation per line: official HTTPS URL | RFC 3339 UTC time | sha256- digest. Use the evidence lookup for retained observations, or enter the exact values from a new observation.

[Look up records](https://j3brns996.github.io/Modelo/propose/?operation=batch#lookup-candidate_evidence)

**Acceptance checks:** One check per line, up to 25. For example: the named model and its evidence agree.
