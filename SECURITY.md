# Security Policy

## Private reporting status

As of 2026-09-02, GitHub private vulnerability reporting is not configured for
this repository. There is no promised private or confidential repository
channel today.

## What not to publish

Do not post credentials, access tokens, account IDs, private commercial terms,
provider offer tokens or exploit details in public issues, pull requests or
comments.

## Sensitive reports

Maintainers must establish and verify a private reporting channel before
sensitive reports can be accepted. Until that exists, keep sensitive material
out of public repository traffic.
